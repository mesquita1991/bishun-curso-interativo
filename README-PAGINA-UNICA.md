# Bǐshùn — página única

Somente `index.html` é servido como página. Os demais documentos HTML públicos foram arquivados exatamente nos dados `archive/legacy-1.json`, `archive/legacy-2.json` e `archive/legacy-3.json`.

O site reúne o manual de 198 páginas (incluindo figuras), 9 etapas e 300 unidades, as 302 lições da trilha, o inventário de escrita e pronúncia, 48 mnemônicos e os dados pós-padrão. Todos os arquivos curriculares e motores originais permanecem preservados, mas não são executados na página. A página não utiliza navegação multipágina, avaliação ou armazenamento de progresso.

Verificação: `npm run check`.
