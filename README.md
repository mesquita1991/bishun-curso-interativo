# 笔顺 · Curso interativo

Site estático em HTML, CSS e JavaScript sobre ordem dos traços chineses.

## Versão

**2.0.1 — Som & domínio**

Principais recursos:

- 11 módulos progressivos;
- animação e treino individual de 24 caracteres;
- pronúncia normal e lenta por síntese de voz chinesa do dispositivo;
- dicas individualizadas de tom e articulação;
- modos guiado e desafio;
- métricas locais de escuta, tentativas, erros, conclusões e domínio;
- painel, filtros, desafio diário, tema escuro e acessibilidade;
- PWA instalável e progresso salvo localmente.

## Executar localmente

```bash
python3 -m http.server 4173
```

Abra `http://localhost:4173`.

## Validação JavaScript

```bash
node --check app.js
```
